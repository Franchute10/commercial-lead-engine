# AEOS project relationship

This repository is a **satellite research/engineering project**, not AEOS Core.

The project charter, current roadmap, cross-repository status and handoff rules are maintained in the canonical [AEOS Project Handbook](https://github.com/Franchute10/autonomous-agent-economy/blob/docs/aeos-project-handbook/PROJECT_HANDBOOK.md). After that handbook PR merges, use the `main` link.

## Current boundary

- This engine explores public commercial research and opportunity signals. It is not an autonomous agent runtime and is not currently integrated end-to-end with AEOS Core.
- Tavily searches its public index; it does not access private Facebook groups or authenticated Nextdoor content. A search result is a candidate, not a verified buyer or contactable lead.
- Search, qualification, human review, source permissions and measured usefulness must be treated as separate steps.
- Do not promise or sell leads until an agreed pilot demonstrates source accuracy, fit, freshness, geography, public response path and customer usefulness.
- No automated outreach is authorized by this repository's current pilot.

Before starting work, read the AEOS handbook and [this repository's intent evaluation plan](docs/intent-evaluation.md). Confirm the branch/commit and check the open PR stack before editing. Keep credentials and local search journals out of Git.
